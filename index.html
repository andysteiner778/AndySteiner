Currently Running Validation Testing Neural Encoding & AI Pre-Registered Analysis

Meta TRIBE v2 Brain-Encoding Run on a Purpose-Built Video Stimulus

Ran Meta's TRIBE v2 brain-encoding model on a 50-second video I built specifically to test it, producing predicted cortical responses across 20,484 fsaverage5 vertices at 1 Hz. Six directional predictions were locked before the run; it scored 4 of 6 and was not revised upward. A second run with the segment order reversed and the startle event moved 30 seconds earlier scored 7 of 7, so the speech and startle effects follow content rather than clip position. The pipeline tracks semantic and acoustic content, not just low-level image statistics: between a speech segment and a silent landscape, predicted language response swings +0.86 to -1.28 and auditory +1.18 to -1.22, both over 2 SD and both surviving removal of the shared across-region signal. During a startle event, salience regions were the most elevated of eleven (+0.92, next region +0.02), peaking 2 s after onset.

Known limitation, stated up front: the eleven region groups are not independent. Mean inter-region correlation was 0.665 then 0.483, and scene-selective correlates with early visual at r = 0.998 then 0.989, so across both runs those two cannot be told apart and no scene-specific claim is made. These are model predictions for an average subject, not measurements, and nothing has been validated against recorded BOLD. Reversing three segments leaves the middle one in the middle, so the trailer's position was not properly controlled and a third run is needed to close that.

Real output from both runs. Source video frames are copyrighted and cannot be shown. Stimulus assembly, loudness normalisation, and two bugs found in Meta's released install are documented under View Code.

Verified BCI Real-Time

EEG Flappy Bird (Real-Time BCI)

A complete Flappy Bird clone (pipes, collisions, scoring, restart flow, high scores) controlled by ocular-blink artifacts read from a Backyard Brains SpikerBox over serial at 223,200 baud. Runs a threaded signal-processing loop (rolling baseline subtraction, adaptive blink threshold tunable live with UP/DOWN) and renders a live oscilloscope HUD of the EEG waveform under the game. A draggable threshold slider sits in the HUD next to the live trace. This is how you calibrate the blink strength, since everyone's blink amplitude differs. Set the bar too low and minor movements or eye twitches set off the jump. Requires a real SpikerBox to play. A built in EEG simulation is available for demo purposes via command line.

Verified & Working, Needs Refinement BCI Signal Processing

Live EEG Signal Analysis Dashboard

The real-time signal-processing engine behind the EEG work: streams raw EEG from a Backyard Brains SpikerBox over serial, applies a live bandpass + 60Hz notch filter with persistent filter state (scipy sosfilt), extracts Welch PSD band powers (Delta/Theta/Alpha/Beta/Low & High Gamma), and feeds them into incremental PCA plus a periodically recomputed t-SNE embedding, all drawn across a 4-panel live Matplotlib dashboard. A blink-spike detector watches the filtered signal and fires a spacebar keypress, the mechanism that drives EEG Flappy Bird.

The idea behind it: take a resting-state baseline off the SpikerBox, then watch how different brain states pull apart as they pass through successive dimensionality-reduction stages. Band-power features feed an incremental PCA, which feeds a periodically recomputed t-SNE embedding, so distinct cognitive states land in visibly different regions of the low-dimensional space instead of one undifferentiated cloud. It runs end to end on my own hardware and the separation is real. Longer baselines produce sharper clustering, but the blink-spike trigger threshold still needs tuning for each person's blink amplitude.

It also does blink-artifact rejection, with an on/off switch and a threshold slider. A blink is a large, slow deflection that sits inside the 0.5–70 Hz passband, so the bandpass can't touch it, and because power scales with amplitude squared a single blink dumps enormous energy into Delta and Theta. Left alone, that propagates into PCA and t-SNE and the dominant axis of the "neural manifold" turns out to be how recently you blinked. Supra-threshold samples are interpolated across, and windows too contaminated to reconstruct are dropped rather than guessed at. The raw trace stays untouched so blinks are still visible; only the features are cleaned.

Recording above is driven by a reproducible test signal with blinks at known timestamps, so the detector's hits and misses can be scored frame by frame: it currently lands 5/5 with no false positives. The same code path runs unchanged on live SpikerBox input. Demo shows simulated data, but I have successfully run it on a real SpikerBox.

Python • SciPy (sosfilt / Welch PSD) • scikit-learn (IncrementalPCA, t-SNE) • Matplotlib • PySerial • pynput

Facebook Marketplace Car Alert Bot

Real-Time Elder-Care Fall Detection

A local monitoring pipeline combining MediaPipe pose estimation (fall detection via center-of-gravity + body aspect-ratio) with YOLOv8 object detection (tracks held items like phones near the hands), served as a live Flask dashboard with a privacy shield that blanks the video feed until an emergency is confirmed.

Held-item detection has its own on/off switch in the dashboard. It's the expensive half of the pipeline (a YOLO forward pass every frame), and fall detection runs entirely off MediaPipe pose, so turning items off frees up frame budget without touching the safety feature. The item detection was more proof of concept, it could be used to trigger an emergency, or can be disabled.
